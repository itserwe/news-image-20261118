# The World Today — 18 November 2026

A one-day newspaper front page summing up the world's news of Wednesday,
18 November 2026, as an entry for the make.fun bounty
[news-image-20261118](https://make.fun/bounty/news-image-20261118).

- `main.py` — the entry program (Python 3.13, standard library only): copies
  `entry.png` to `/output/entry.png`.
- `entry.png` — the image: masthead, Shenzhen skyline, and the day's stories:
  the APEC summit in Shenzhen, the US–Iran strikes in the Gulf, Ukraine's
  Kerch Bridge strikes, Nvidia's $115.8bn quarter, the Alaska Senate race,
  the Congo Ebola outbreak, and Voyager 1 reaching one light-day.

Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
